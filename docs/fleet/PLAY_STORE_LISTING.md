- **Does your app collect or share any of the required user data types?** → **Yes**

### Üçüncü taraf paylaşımları

Veriler **paylaşılmıyor** ama **3. taraf hizmetlere gönderiliyor** (proses + storage):

- **Cloudinary** — araç fotoğrafları storage (signed upload, public URL'ler kontrolün altında)
- **Google Maps SDK** — harita render + reverse geocoding (konum API'sine kullanıcı bilgisi gönderilmez)
- **Firebase Cloud Messaging** — push token routing (mesaj içeriği değil sadece metadata)
- **Sentry (Functional Software Inc.)** — crash + performance event'leri (id + email + crash stack; IP toplanmıyor)

Privacy policy'de bu 4 hizmet açıkça belirtilir (https://drivermesh.com/privacy). Data Safety formunda "shared with 3rd parties" alanlarına işaretleme **No** çünkü bunlar "service providers" (data processor), Play Console terminolojisinde "shared" sayılmaz.

## 7) Test Account Credentials (review için)

Play Store review ekibi uygulamayı incelemek için **demo bir hesaba** ihtiyaç duyabilir. **Demo modu** zaten uygulama içinde var — login gerek yok, "Demo App" butonu ile tek dokunuş. Bu bilgiyi Play Console'da **App content → App access → "Login required to access app"** sorusuna **No** olarak işaretle, "Demo mode is available without login" notu ekle.

Eğer login gerektiren bir akış da test edilmek istenirse, prod environment'a sandbox bir patron + şoför hesabı oluşturup credentials'ları "Notes" alanına yaz:

```
Demo mode (no login required):
1. Open the app
2. Tap "Demo App" button on the welcome screen
3. Explore all features (Home, Fleet, Map, Jobs, Account)
4. Account → "Sign Out" returns to welcome screen

Optional: Production sandbox accounts (if needed)
- Owner:  patron-review@drivermesh.com  / Test1234!
- Driver: sofor-review@drivermesh.com   / Test1234!
- Sandbox organization is isolated from real customer data.
```

> **Yapılacak:** Sandbox owner + driver hesaplarını Supabase'de manuel oluştur (real_account_creation_path), credentials'ları 1Password'a kaydet. **Şimdilik demo mode yeterli olabilir.**

## 9) Pre-launch Report Issues

İlk submission sonrası Play Console otomatik **Pre-launch Report** çalıştırır (5 fiziksel cihaz × 5 dakika robot test). Yaygın çıkacak uyarılar:

- **Accessibility:** TalkBack içerik açıklamaları eksik olabilir bazı view'larda. Memory'de `project_a11y_audit.md` yok — release sonrası iterate.
- **Performance:** Düşük-end cihazda (4GB RAM) cold start > 3s olabilir. R8/Sentry inflate ediyor; sonraki release'de bundle splitting (per-ABI) düşünülebilir.
- **Crash:** Pre-launch test akışında demo girmez — crash patlatıyorsa Sentry'e gelir, dashboard'tan triage.
