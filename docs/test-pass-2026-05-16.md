## 4. Test Sırasında Yapılan Manuel DB Fix'ler

UI/web shim engelleri nedeniyle aşağıdaki SQL'ler test akışını ilerletmek için elle uygulandı. **Production code path'i değişmedi** — bunlar test setup workaround'u, prod bu state'lere normalde UI ile ulaşır:

1. **service_area** (Lojistik Üssü MapPicker web'de devre dışı):
   ```sql
   UPDATE fleets_visibility SET service_area = ST_Buffer(...30000m)
   ```
2. **organizations.hq_lat/lng/address** (aynı sebep):
   ```sql
   UPDATE organizations SET hq_lat=41.0256, hq_lng=28.9742, hq_address='Galata, İstanbul'
   ```
3. **operating_hours** (BUG-DB2 düzeltmesi):
   ```sql
   UPDATE fleets_visibility SET operating_hours = '{"tz":"Europe/Istanbul","mon":[{"start":"00:00","end":"23:59"}],...}'
   ```
4. **vehicles.current_user_id** (test-resume.md §6'da önerilen alternatif yol — UI'da "Üzerine Al" butonu bulunamadı):
   ```sql
   UPDATE vehicles SET current_user_id='<mehmet>' WHERE plate='34 TST 002'
   ```
5. **customers seed** (BUG-RIDE3 workaround):
   ```sql
   INSERT INTO customers(auth_user_id, phone, full_name, language) VALUES ('<selin>', '+905551234567', 'Selin Yıldız', 'tr')
   ```
6. **Selin auth user** (devSignIn için `dev-customer@drivermeshride.local` REST signup):
   ```
   POST /auth/v1/signup { email, password }
   ```
