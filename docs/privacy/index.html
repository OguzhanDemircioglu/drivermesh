7. Güvenlik Önlemleri

Privacy Policy

This policy applies to the DriverMesh Fleet (operator/driver app, package com.drivermesh.android) and DriverMesh Ride (passenger app, package com.drivermesh.ride) services. By using the services you accept this policy.

1. Data Controller

Contact: oguzhanturgut611@gmail.com
Location: Türkiye
Web: github.com/OguzhanDemircioglu/drivermesh

2. Personal Data Processed

  • Identity: full name, phone number (verification), email (optional)
  • Location: GPS — only while the app is open, for driver-passenger matching + ETA
  • Device: push notification token (FCM), device language, app version, OS version
  • Usage: trip history, job state (Fleet)
  • Fleet operator side (private): vehicle plate, photo, maintenance notes, driver assignment
  • Crash data: stack trace, app version, device model — no personal data

3. Purposes & Legal Basis

  • Trip matching + completion (performance of contract, GDPR Art.6(1)(b))
  • Driver-passenger communication (performance of contract)
  • Phone OTP verification (pre-contractual necessity)
  • Crash reporting + performance (legitimate interest, GDPR Art.6(1)(f))
  • Push notifications (explicit consent via system permission)

5. Retention Periods

  • Active account data: until account deletion
  • Deletion request: 30-day recovery window, then permanent erasure
  • Trip history: 5 years (tax/compliance legal requirement)
  • Crash logs: 90 days (Sentry default)
  • Push token: while account is active

6. User Rights (KVKK Art.11 + GDPR)

The user has the right to:

  • Know whether data is being processed
  • Request access if processed
  • Request correction of inaccurate/incomplete data
  • Request deletion — in-app: Account → Delete my account
  • Request portability to another service
  • Object to processing
  • Request human intervention against automated decisions

Requests: oguzhanturgut611@gmail.com

7. Security Measures

  • All traffic encrypted via TLS 1.2+
  • Database at-rest encryption (Supabase managed AES-256)
  • Row Level Security (RLS) — users see only their own data
  • Phone OTP-based authentication (no passwords)
  • API keys restricted by package + SHA-1
  • Personal data masked in log files

8. Children

DriverMesh services do not target users under 13. Users under 18 require legal guardian consent. If we discover a child's data is being processed, it is deleted within 30 days.

9. Cookies and Similar Technologies

The mobile app does not use browser cookies. Session data (Supabase JWT refresh token) is stored locally on the device via AsyncStorage and deleted on logout.

10. Complaint Rights

  • Türkiye: Personal Data Protection Authority (KVKK) — kvkk.gov.tr
  • EU: local data protection supervisory authority (GDPR Art.77)

11. Changes

When the policy is updated, it is published on this page and the "Last updated" date is changed. Significant changes are notified in-app.
